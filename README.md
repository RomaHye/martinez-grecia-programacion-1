## Propósito del repositorio

Este repositorio tiene como propósito almacenar las evidencias realizadas durante la materia de Programación 1, incluyendo prácticas, tareas y proyectos desarrollados a lo largo del curso.

## Estructura del repositorio

- `practicas/`: contiene las prácticas y ejercicios realizados durante las clases.
- `proyectos/`: contiene los proyectos desarrollados durante el curso.
- `.gitignore`: indica los archivos y carpetas que Git debe ignorar.
- `README.md`: contiene la información y documentación general del repositorio.

## Bitácora de instalación

Para trabajar durante el curso instalé Python, Visual Studio Code y Git en Windows 11.

### Python

Se instaló Python 3 para desarrollar y ejecutar los programas de la materia.

**Versión:** Python 3.13.15

Durante la instalación, inicialmente la terminal de Visual Studio Code no reconocía los comandos de Python. El problema se solucionó reiniciando Visual Studio Code después de instalar Python, permitiendo que la terminal reconociera correctamente la instalación.

### Visual Studio Code

Se instaló Visual Studio Code como editor de código para trabajar con los archivos de Python y administrar el repositorio.

También se instaló la extensión de Python para facilitar el desarrollo y ejecución de los programas.

### Git

Se instaló Git para llevar el control de versiones del repositorio y conectarlo con GitHub.

**Versión:** Git 2.55.0.windows.5

Durante la configuración inicial, Git no era reconocido desde la terminal de Visual Studio Code debido a que todavía no estaba instalado en el equipo. El problema se solucionó instalando Git for Windows y reiniciando Visual Studio Code.

## Cómo clonar y utilizar el repositorio

Para clonar este repositorio en otra computadora se utiliza el siguiente comando:

```bash
git clone https://github.com/RomaHye/martinez-grecia-programacion-1.git
```
Después se debe entrar a la carpeta del repositorio:

```bash
cd martinez-grecia-programacion-1
```

Las prácticas se guardarán dentro de la carpeta `practicas/` y los proyectos dentro de `proyectos/`.

Para guardar y subir cambios al repositorio se pueden utilizar los siguientes comandos:

```bash
git add .
git commit -m "Descripción de los cambios"
git push
```
